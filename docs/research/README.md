| [technical-research.md](technical-research.md) | The technical topics from section 8 of the assignment: APIs, webhooks, event-driven processing, execution engines and queues, scheduling, data transformation, failure handling, credential security, and the limitations and opportunities in existing products. |
| [platforms/](platforms/) | The detailed notes behind the comparison, one per product: [n8n](platforms/n8n.md), [Zapier](platforms/zapier.md), [Make](platforms/make.md), [Power Automate](platforms/power-automate.md), [Workato](platforms/workato.md), and [Pipedream and Activepieces](platforms/pipedream-and-activepieces.md). |
